# Crush Guesser asset drop folder

Place temporary or final exported image assets here when they are ready to wire into the prototype.

Suggested filenames matching the current mockup pass:

- `locker-interior.png` — warm open-locker background / vertical metal frame.
- `dialogue-box.png` — optional pixel dialogue frame if replacing the CSS version.
- `torn-lined-paper.png` — bottom note sheet with binder holes.
- `trapper-keeper-closed.png` — closed Trapper Keeper prop.
- `trapper-keeper-open.png` — reveal/open Trapper Keeper prop.
- `side-combo-lock.png` — vertical lock strip on the Trapper Keeper.
- `combo-wheel.png` — individual large combination wheel.

The app currently uses CSS placeholders so these files are not required to run.
